# Swasthya Grid: Project Submission Description

A federated AI control tower for India's public health network that forecasts medicine demand, predicts PHC stock-outs, monitors operational bed/staff capacity, and recommends deterministic cross-district resource redistribution. Built with verified Government of India datasets (LGD, Census, MoHFW, HMIS, IMD, NLEM) and calibrated facility simulations, it demonstrates decentralized multi-state federated learning (FedAvg) and leverages Google Vertex AI / Gemini 3.8 Flash for grounded operational intelligence and administrator briefings.
